What it asks for, and nothing else
  • gmail.readonly — to read the thread against the contract.
  • gmail.compose — to put a draft in your drafts folder.

Google has no draft-only permission, so gmail.compose would technically allow sending. This codebase contains no send path, and a test fails if one ever appears. Nothing leaves your account without you pressing send yourself, in Gmail.

This needs a Google OAuth client, which only the person running the app can create. Once credentials.json is in the project root, this page turns into a Connect button.

  1. In the Google Cloud console, create a project and enable the Gmail API.
  2. Configure the consent screen. While it is unverified, add yourself under Test users — Google caps unverified apps at about a hundred people and shows a warning screen.
  3. Create an OAuth client ID of type Web application, with this exact redirect URI: {{ url_for('connect_callback') }}
  4. Download the JSON, save it as credentials.json in the project root, and reload this page.

credentials.json is listed in .gitignore, as is the database the token is stored in. Neither belongs in a public repository.
