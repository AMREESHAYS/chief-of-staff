For whoever runs this server

Google will not let an unregistered application ask anyone for access. Registering takes about ten minutes and is done once, not per user.

  1. In the Google Cloud console, create a project and enable the Gmail API.
  2. Configure the consent screen. While the app is unverified, add yourself under Test users — Google caps unverified apps near a hundred people and shows a warning screen.
  3. Create an OAuth client ID of type Web application with this redirect URI: {{ url_for('connect_callback') }}
  4. Download the JSON, save it as credentials.json beside the code, and reload this page.

That file identifies the application to Google. It is not a user's password and it is not a key anybody types in. It is listed in .gitignore, as is the database the tokens live in.
